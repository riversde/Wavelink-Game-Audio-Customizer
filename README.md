# Wavelink Game Audio Customizer by PR FRAG

Windows x64 VST3 game audio effect for Wave Link: customizable ten-band EQ, optional clarity, Directional Focus, English/Spanish interface and editable game presets.

[Download the latest release](https://github.com/riversde/Wavelink-Game-Audio-Customizer/releases/latest)

## Install

Extract the complete release ZIP. Close Wave Link, back up the existing plugin, and copy the complete WavelinkGameAudioCustomizer.vst3 bundle into C:\Program Files\Common Files\VST3. Restart Wave Link and scan effects if needed. Open the effect on your Game channel. Read RELEASE-2.0.3.md in the package for installation and rollback details.

For the tested ZERO:RED / Wave:3 setup, choose Warzone MW4 / PR FRAG v2 - Directional, then Apply: +16 dB output, Focus 50%, clarity +3 dB / 40%, EQ strength 100%. Lower headphone playback volume before applying greater gain. The v1 profile and Restore baseline preserve the earlier configuration.

## Scope

Directional Focus changes stereo centre/lateral contrast. It cannot reconstruct height or spatial objects, or distinguish enemy footsteps from your own. GAME spatial status reports capability, not proof that Dolby Atmos is active. Dolby is configured separately. The included interface preview uses synthetic meters and processes no audio.
